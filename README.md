# kaisaucedo.com

My personal site. Live at [kaisaucedo.com](https://kaisaucedo.com).

Plain HTML, CSS, and a little JavaScript. No framework, no build step. The home page decodes its text on load like a terminal, then links out to a page for each project:

- **Loan Origination Platform**: a financing-intake platform for a commercial lending brokerage, live with real applicants
- **Labor Reporting Automation**: a one-click Excel VBA tool that replaced a construction department's manual weekly reporting
- **Personal Agent Stack**: one shared memory layer for every AI agent I run
- **Wave Glider Pressure Vessel**: UCSD capstone with NIWC Pacific
- **Bogger Builds**: paid social campaign, about 8x return on ad spend
- **OFF THE TOP** and **KAIKAI**: two brands I built from zero

## Structure

```
index.html        home
<project>.html    one page per project
style.css         shared styles
site.js           the text-decode animation
```

Deployed on Netlify from the `main` branch.
