The problem

Every AI tool I used started from zero, and every task needed me to drive it. The context lived in my head and in a dozen apps, and the repetitive work never stopped.

The build

An automated system of agents that share one memory and start themselves.

  1. Orchestration. An orchestrator breaks complex tasks into parts and hands them to subagents that work in parallel.
  2. Shared memory. An Obsidian knowledge base, exposed through a local MCP server, gives every agent persistent memory that carries across agents and across models.
  3. Skills. Each agent gets task-specific skills and instructions, so it starts every job already knowing how that job is done.
  4. Triggers. Events and schedules kick off agents and loops automatically. Nobody has to start them.

In production

The system takes the monotonous work off my plate, and it operates live websites. On FLS Capital Advisors, agents handle customer support and ongoing site maintenance and operations. The whole system runs on its own.

Guardrails

  • Agents draft. I send. Nothing goes out under my name without me.
  • Anything irreversible needs my approval first.
  • Before I approve a command, the agent explains what it does in plain language.
  • No secrets go into the shared memory.
