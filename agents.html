One memory layer for every agent I run, so I stop re-explaining my life to each one.

Hermes, Claude Code, Docker, MCP (Model Context Protocol), Obsidian, Notion, cron

The problem

Every artificial intelligence (AI) tool I used started from zero. I kept re-explaining my work, my projects, and my deadlines to each one. The context existed, it just lived in my head and in a dozen apps.

The build

One memory layer that every agent reads from and writes to.

  1. Shared memory. An Obsidian knowledge base, exposed through a local MCP server, acts as memory for Claude, Claude Code, and Hermes alike.
  2. Agents. Hermes runs in Docker. Claude Code handles engineering work. Both work from the same notes.
  3. Schedules. Agents run on cron for recurring work, like checking deadlines and preparing drafts.
  4. Capture. Messy quick notes from my phone get triaged into tasks and deadlines in Notion. This part is still in progress.

Guardrails

  • Agents draft. I send. Nothing goes out under my name without me.
  • Anything irreversible needs my approval first.
  • Before I approve a command, the agent explains what it does in plain language.
  • No secrets go into the shared memory.
